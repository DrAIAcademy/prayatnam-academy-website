# Prayatnam Academy Website

A GitHub Pages-ready static website for Prayatnam Academy.

## Edit before publishing

1. Replace all `+91XXXXXXXXXX` placeholders with your real call/WhatsApp number.
2. Replace `info@prayatnam247.com` with your real email if needed.
3. Update the Google Maps embed query when the exact location is final.

## Deploy on GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Go to **Settings → Pages**.
4. Select **Deploy from branch**.
5. Choose **main** and **/root**.
6. Save.
