# Prayatnam Academy Website

GitHub Pages-ready static website for Prayatnam Academy.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Before Publishing
Replace these placeholders:
- `+91XXXXXXXXXX` with your actual call/WhatsApp number.
- `info@prayatnam247.com` with your official email.

## Visitor Counter Note
The included visitor counter counts visits from the current browser/device using localStorage. A true all-user website counter requires a backend, Google Analytics, Cloudflare Web Analytics, or a third-party counter service.
