# Prayatnam Academy Website

A responsive one-page website built with HTML, CSS and JavaScript for GitHub Pages hosting.

## How to use

1. Replace all instances of `+91XXXXXXXXXX` and `91XXXXXXXXXX` in `index.html` with the real phone / WhatsApp number.
2. Optional: update app links, photos, logo, and social links when ready.
3. Push these files to a GitHub repository.
4. Go to repository Settings → Pages → Deploy from branch → select `main` and `/root`.

## Files

- `index.html` — website content and structure
- `styles.css` — design and responsive layout
- `script.js` — mobile menu behavior
